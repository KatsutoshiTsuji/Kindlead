Kindlead - Kindle 无障碍电子书阅读器 (NVDA 插件)

作者: 辻 胜利 (Debugon) & Antigravity

概述

Kindlead 是一款专为 NVDA 屏幕朗读软件设计的插件。通过 Google Gemini 多模态视觉 AI，自动翻页捕获 Kindle for PC 中打开的电子书（特别是固定版式、纯图片图书），将其转换为包含标题层级树、可点击目录链接的完全无障碍 HTML 文档。

使用方法

  1. 在 Google AI Studio 免费获取 Gemini API 密钥。
  2. 打开 NVDA 菜单 (NVDA + N) → 首选项 → 设置 → Kindlead 类别，粘贴您的 API 密钥。
  3. 打开 Kindle for PC 并将要阅读的图书翻至开头（封面或第 1 页）。
  4. 打开 NVDA 菜单 → 工具 → Kindlead - Kindle 图书结构化捕获 (&K)...。
  5. 确认提示对话框并点击“开始捕获”。在 Kindle 自动翻页期间，请勿触碰键盘和鼠标。
  6. 捕获与 AI 处理完成后会播放提示和弦音，并在默认浏览器中自动打开结构化 HTML 电子书。

阅读时的键盘操作（NVDA 单键导航）

  • H 键: 跳转到下一个标题（Shift+H 跳转到上一个）
  • 1〜6 键: 跳转到标题级别 1〜6（章节与小节跳转）
  • 7 键: 跳转到专栏・边栏（Shift+7 跳转到上一个）
  • 8 键: 巡回浏览注释・脚注（Shift+8 跳转到上一个；点击末尾的“↩”链接即可瞬间返回正文阅读位置）
  • 9 键: 跳转到图表说明与图说文字（Shift+9 跳转到上一个）
